## Learnings

**The single most valuable thing this session established: for every claim, name the thing that
would fail if the claim were false. If the answer is "nothing, but it is written down", the
claim is not evidence.** Roughly nine defects fit that shape — a required gate with no runner
(G6), an unenforced `mod.rs` convention, an unused dependency feature documented as *required*,
a frozen criterion never asserted on the wire (`StreamEvent::Usage`), a changelog rule with no
signal, a contract table nobody walked through, and a bug-log entry citing a regression test
that did not exist. **Not one was found by a stage's own gate passing.**

Defects worth knowing about before touching the same areas:

- **B32 is the one that should change how you test.** Four `parse_agy` tests passed only because
  the developer's real `~/.gemini` satisfied agy's subscription gate — so M1's named gate, and
  therefore ubuntu/windows/macos CI, was **red** while every local run was green. Gate **G3d**
  now runs the whole suite with `HOME`/`USERPROFILE` redirected to an empty directory. If you add
  a test that touches vendor auth, **give it a scratch home; do not inherit one.**
- **Two defects were in briefs I wrote, not in code.** B38: the strings leg's selection made it a
  false-negative machine (268 toolchain artefacts like `-0x`/`-1v`, while every real flag and
  every policy word was missing). B39: I asserted `codex.js` must contain `--json` and
  `grep -c` returns **0** — it is an 8.8 KB dispatcher, and the real artefact is
  `node_modules/[<scope>/]codex-<platform>/vendor/<triple>/bin/codex[.exe]`. An agent spent 30
  minutes unable to satisfy an impossible instruction. **When an instruction cannot be
  satisfied, suspect the instruction.** `grep -c` on the file the instruction was *about* broke
  the deadlock.
- **Measured, not assumed:** a vendor stores its flag table **concatenated**
  (`--sandbox-policy-cwd--permission-profile--use-legacy-landlock--managed-networkcommand`), and
  because kept strings are capped at 200 chars, a flag change late in a blob was invisible.
  `src/watch/strings.rs` now splits on `--`. A long flag never contains a double hyphen.
- **`2>&1` on native stderr aborts PowerShell** under `$ErrorActionPreference = 'Stop'` via
  `NativeCommandError`. The M6 non-TTY gate failed **silently** because of it — no `FAIL` line,
  just exit 1, the exact defect it was written to catch. The bash runner has the twin: a failing
  command substitution in an assignment trips `set -e` before anything prints.
- **Correcting a frozen table invalidates artefacts written from it.** The M6 keybinding table
  was corrected mid-flight and stage A's test helper still pinned the old row (B26).
- **`cargo test` compiles the working tree, not the index.** A commit is only verified if the
  working tree equals what you committed — which is why a wave whose shared files interleave
  became one commit.
- **Two `crossterm` versions are in `Cargo.lock`** (`ratatui 0.29` needs `0.28.1`). Recorded,
  not changed: the pair is what was verified, and the two never share a type.

**Environment facts a fresh session needs:**

- **Subagent delegation returned `402 Insufficient Balance`** near the end of this session, so
  the last items were done by hand. Check credit before planning a fan-out; the M11 contract is

- `advisor` was quota-blocked for the whole session (resets in ~78 h at the time of writing).
- No git tag exists in this repo, and `Cargo.toml` is still `version = "0.1.0"` after eleven

## Action Items & Next Steps

**1. M11 — the tool suite. Contract is frozen; no code. This is the next milestone.**
`DESIGN.md` §20, `ACCEPTANCE.md` §19, `ROADMAP.md`. Three stages, one gate binary each:
`tests/tools.rs` (read-only tools), `tests/tools_bash.rs` (bash, scoped), and a spawn-policy
unification guarded by `tests/tool_loop.rs` + `tests/process.rs`.

The **first** decision is already made and recorded, because implementing it is what revealed
it: **M9's loop has no user in it.** `agy --print` and `codex exec` are one-shot, claude's SDK
mode streams, and the TUI is not the only entry point — there is nowhere to ask "may I run this?"
mid-turn. So a tool is enabled in config with a declared scope or it is not offered: no per-call
approval, no timeout-then-proceed. Consequences that are now checks: the default with no config
is **no tools at all** (today's behaviour, so upgrading cannot make a setup executable);
`bash_allow` checks **`argv[0]` before the spawn**; the workspace root is a ceiling checked on
the **resolved** path (`..` and symlinks are the two ways a textual check is wrong); and `bash`
must **not** become a third copy of the spawn policy — M11 unifies `ChildTransport` into
`process.rs` instead.

**2. ACCEPTANCE §14's S1–S17.** S15 and S17 are worth batching: S15 is three signature widenings
in one function (`render_report` should take `failed: &[NewsSource]` rather than a
`FAILED_SOURCE_MARK` sentinel, `Drift` should carry `Option<String>` for the pie file, and the REA
mode should be a parameter); S17 is the fused-flag-table duplication the strings leg's two
selection paths create. S2 (`println!` panics on a broken pipe — `pie -p … | head -1` exits 101)
is the cheapest remaining panic.

**3. Judge the TUI by hand.** `cargo build --release` then `./target/release/pie.exe tui`. The
verdict deliberately does not claim it is usable: keystrokes are covered through the reducer and
rendering through the buffer, but "does this feel usable" is not automatable.

**4. The release — needs the user's decision.** `VERSIONING.md` requires promoting the
`[Unreleased]` block and tagging **in the same commit**. `Cargo.toml` is `0.1.0` after eleven
`feat:` milestones, and 0.x permits MINOR for breaking changes, so the number is a choice rather
than an arithmetic result. S12 records why no mechanical gate is worth adding here: "was the
changelog updated" is not decidable from the repo, so any cheap check would pass for the tree
that was wrong.
